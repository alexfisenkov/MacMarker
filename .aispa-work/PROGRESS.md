# MacMarker — состояние

Последняя сборка: `.aispa-work/2026-10-29-macmarker/` — v0.1.0 опубликована, Developer ID подписан, Apple notarization Accepted, установлена и запущена.

## Договорились — не пересматривать
- «очень быстро, без кучи проверок, критиков» — R14; critics/review/blind agents отключены владельцем.
- Только четыре настройки: цвет, непрозрачность, толщина и удерживаемая горячая клавиша — R07–R10/R15.
- «не на две-три секунды, а пока зажато ... отпускаю ... медленно растворяется» — R03/R04.
- Открытый MIT репозиторий и установленный MacMarker; это самостоятельное Mac-приложение поверх Sidecar.

## Не доделано
- R01/R02: физическая приёмка Apple Pencil на реальном iPad/Sidecar владельца — NOT_RUN. Проверены CI, lifecycle smoke, подпись, нотарификация, установка и окно приложения; это не заменяет реальный штрих Pencil.
- Фактический повторный запуск после нового входа в macOS не проверялся; регистрация автозапуска отображалась включённой.

## Известные баги
- Открытых подтверждённых багов приложения нет.
- Системно зарезервированные клавиши могут не перехватываться; палец/мышь во время удержания тоже относятся к pointer input.
- Локальный Xcode обновился с26.6 до27.1 во время работы и запросил лицензию, CLT содержит несогласованный private PackageDescription ABI. Систему не меняли; финальный бинарник взят из успешного GitHub CI, SHA caeb47d9d89e69ae0c40dad8aae06e9e754bb015. Для будущей локальной пересборки нужен исправный toolchain.
