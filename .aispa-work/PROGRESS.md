## Известные баги
- Открытых подтверждённых багов приложения нет.
- Фактический повторный запуск после нового входа в macOS отдельно не проверялся; регистрация автозапуска отображалась включённой.
- Системно зарезервированные клавиши могут не перехватываться; палец/мышь во время удержания тоже относятся к pointer input.
- Локальный Xcode обновился с26.6 до27.1 во время работы и запросил лицензию, CLT содержит несогласованный private PackageDescription ABI. Систему не меняли; финальный бинарник взят из успешного GitHub CI, SHA caeb47d9d89e69ae0c40dad8aae06e9e754bb015. Для будущей локальной пересборки нужен исправный toolchain.
